# MSFS VFR Bridge

MSFS VFR Bridge displays live aircraft position, recent flight trail and selected flight data from Microsoft Flight Simulator 2024 on supported web maps in Microsoft Edge on Windows and Android.

## Install

[Install the extension from Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/gbjojhhojigjgcpblahphmlliiibmjec)

[Download the Windows Bridge and get support on Flightsim.to](https://flightsim.to/addon/119118/msfs-vfr-bridge-live-aircraft-tracking-for-msfs-2024)

For simulator tracking, install the Windows Bridge on the PC running Microsoft Flight Simulator 2024. On Windows, the extension receives telemetry through native messaging. On Android, connect to the same local network as the PC and scan the QR code displayed by Bridge, or enter its local address in the extension settings.

The optional Device GPS mode displays your device's location independently of the simulator and Windows Bridge.

## Supported maps

- [Microsoft Flight Simulator Flight Planner](https://planner.flightsimulator.com/)
- [LPS SR VFR Manual](https://gis.lps.sk/vfrm/)
- [AirQuest 3](https://v3.airquest.cz/)
- [AISView](https://aisview.rlp.cz/)

## Route and flight-log features

The updated extension supports importing AirQuest routes into the LPS map, displaying terrain elevations, changing planned speed and recording waypoint passage times in a flight log. Available airport and airspace information opens in detail cards. A movable Bridge button provides access to controls on supported pages.

Feature availability depends on the extension version currently published in Edge Add-ons. See the download page for release notes and installation guides.

## Updates

Edge manages updates for the extension installed from Microsoft Edge Add-ons. Update the Windows Bridge by extracting the latest download and running the included Windows installer.
