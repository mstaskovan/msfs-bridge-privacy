# MSFS VFR Bridge

See your Microsoft Flight Simulator 2024 aircraft position, recent trail and selected flight data in Microsoft Edge on Windows or Android. Use the flight log and elevation profile to plan and review simulated VFR flights in AirQuest 3 and on the Slovak LPS VFR map.

## Install

1. Install the extension in Microsoft Edge on Windows or Android. [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/gbjojhhojigjgcpblahphmlliiibmjec)
2. On the PC running MSFS 2024, extract the Windows Bridge ZIP and run `Windows\Install-Windows.cmd` under your regular Windows account. Then open MSFS VFR Bridge from Start. [Windows Bridge download and support on Flightsim.to](https://flightsim.to/addon/119118/msfs-vfr-bridge-live-aircraft-tracking-for-msfs-2024)
3. On Android, connect to the same local network as the PC. Enable **Android over Wi-Fi** in the Windows app and scan its QR code from the extension settings or enter the displayed local address.

The Windows app includes a test flight for checking live tracking without starting MSFS. Optional **Device GPS** mode uses your device location independently of the simulator and the Windows app.

## Supported maps

| Map | What you can do |
| --- | --- |
| [Microsoft Flight Simulator Flight Planner](https://planner.flightsimulator.com/) | Track and follow the aircraft on the main map and supported georeferenced charts. |
| [AirQuest 3](https://v3.airquest.cz/) | Track the aircraft on the main map. Open an AirQuest route to use the flight log and elevation profile directly on AirQuest. |
| [LPS SR VFR Manual](https://gis.lps.sk/vfrm/) | Track the aircraft, open an AirQuest route with the flight log and profile, and view selected Slovak VFR reporting points with landmark descriptions. |

## Flight log and elevation profile

Open an AirQuest route and use the **Bridge** menu to open the log and profile in AirQuest or show the route on LPS. You can reverse the route for a return flight and compare planned and recorded waypoint times.

The profile shows terrain, airspace and planned altitude. Add altitude targets at individual waypoints and use an aircraft performance profile to estimate where to complete the climb and begin the descent. Use forecast winds or enter the wind from your simulator weather settings. Aerodrome details can show available runways, frequencies, METAR and a wind-based runway suggestion.

## Updates

The current release pairs **Edge extension 0.7.0** with **Windows Bridge 0.5.0**. Edge manages extension updates from Edge Add-ons. To update the Windows Bridge, extract the new ZIP and run the included installer.
