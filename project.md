# MSFS VFR Bridge

MSFS VFR Bridge displays your live aircraft position, recent flight trail,
and selected flight data from Microsoft Flight Simulator 2024 on supported
maps in Microsoft Edge.

[Download the Windows Bridge and get support on Flightsim.to](https://flightsim.to/addon/119118/msfs-vfr-bridge-live-aircraft-tracking-for-msfs-2024)
