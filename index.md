# Privacy Policy for MSFS Bridge for Microsoft Edge.

MSFS Bridge receives simulated aircraft telemetry from the separately
installed Windows Bridge application on the same computer. The extension
uses this data to display the simulated aircraft’s position, recent flight
trail, and selected flight data on supported maps.

Extension preferences are stored locally in Microsoft Edge. The developer
does not receive the simulator telemetry or your extension preferences.

If you use the optional Mapy.com integration, the extension keeps the
project API key you enter in memory while the map tab is open. It sends
the key directly to Mapy.com to request map metadata and tiles. These
requests are subject to Mapy.com’s privacy practices.

For privacy questions, contact the developer through the
[MSFS Bridge listing on Flightsim.to](https://flightsim.to/addon/119118/msfs-vfr-bridge-live-aircraft-tracking-for-msfs-2024).
